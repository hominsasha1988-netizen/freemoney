# Telegram Mini App — Реферальна система (v3)

Обов’язкова підписка на канали + перевірка.

## Що є
- **Гейт підписки** — без підписки на всі канали апка не відкривається
- Кнопки «Підписатись» відкривають канали
- Кнопка «Перевірити підписку»
- Демо-режим (без бекенду) — після перевірки пускає далі
- Готова інтеграція з API (`API_BASE`)

## Налаштування каналів

У `app.js` знайди масив `REQUIRED_CHANNELS` і заміни на свої:

```js
const REQUIRED_CHANNELS = [
  {
    id: null,                    // chat_id (для бекенду)
    username: "your_channel",    // без @
    title: "Мій канал",
    url: "https://t.me/your_channel",
    icon: "📢",
  },
  // ...
];
```

## Реальна перевірка (бекенд)

Фронт вже вміє слати запит:

```
POST /api/check-subscription
Body: { initData, userId, channels: [{username, id}] }
Відповідь: { ok: true, channels: { "username": true/false } }
```

Бекенд має:
1. Перевірити підпис `initData` (HMAC)
2. Для кожного каналу викликати `getChatMember`
3. Бот має бути **адміном** у цих каналах

Коли будеш готовий — зроблю Node.js бекенд під це.

## Демо
Відкрий `index.html` → гейт → «Перевірити підписку» → пускає в апку.
